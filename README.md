# 🛡️ Cybersecurity Python Lab

## Ethical Hacking, Python Automation and Cybersecurity Laboratory

A hands-on cybersecurity laboratory focused on learning ethical hacking, information gathering, network enumeration, security automation, and defensive analysis using Python and Kali Linux.

This project is being developed as a practical learning portfolio based on cybersecurity concepts, Python programming, and controlled laboratory environments.

---

# 🎯 Objectives

The main objectives of this project are:

- Strengthen cybersecurity fundamentals.
- Learn Python for cybersecurity automation.
- Practice information gathering techniques.
- Understand network and service enumeration.
- Develop custom Python security tools.
- Analyze network traffic and protocols.
- Practice vulnerability assessment in controlled environments.
- Learn defensive and Blue Team concepts.
- Document every laboratory professionally.

---

# 🧪 Laboratory Environment

The laboratory is developed using:

- 🐧 Kali Linux
- 🐍 Python
- 🖥️ Virtualized environments
- 🌐 Authorized VPS infrastructure
- 🐳 Docker laboratories
- 🔍 Nmap
- 📡 Network analysis tools
- 🛡️ Intentionally vulnerable applications
