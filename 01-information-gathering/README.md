# LAB 01 — Information Gathering with Python

## Objective

The objective of this laboratory is to learn how Python can be used to automate basic information gathering tasks during authorized cybersecurity assessments.

The exercises focus on collecting publicly available technical information from domains and network services in controlled and authorized environments.

---

## Learning Objectives

During this laboratory, the following concepts will be practiced:

- Python fundamentals.
- Python modules.
- Functions.
- Error handling.
- Domain name resolution.
- IP address identification.
- Basic DNS information.
- Service information gathering.
- Automation of repetitive tasks.

---

## Planned Tools

The laboratory will progressively use:

- Python
- Socket
- Requests
- DNS libraries
- Nmap
- Other authorized security tools
