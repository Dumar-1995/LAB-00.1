# 05 - Network Security

Este módulo contiene herramientas desarrolladas en Python para la recopilación
de información de red y la validación básica de conectividad en entornos
autorizados.

El enfoque del módulo es **local, no invasivo y educativo**, evitando
actividades de explotación, interceptación de tráfico o escaneo masivo.

---

## Objetivos

- Identificar información básica de la configuración de red local.
- Obtener información detallada de las interfaces de red.
- Identificar direcciones IPv4 e IPv6.
- Consultar información como MTU, MAC, estado y flags de las interfaces.
- Validar conectividad TCP hacia puertos específicos.
- Generar resultados en formato legible para humanos.
- Generar resultados estructurados en formato JSON.
- Servir como base para futuros módulos de análisis de seguridad de red.
