# Laboratory Tools

## Overview

This document describes the main tools used throughout the Cybersecurity Python Lab.

The tools are used exclusively for educational purposes and authorized security testing.

---

## Programming

### Python

Python is the primary programming language used in this laboratory.

Current version:

- Python 3.13.12

Python will be used for:

- Automation.
- Information gathering.
- Network analysis.
- Data processing.
- Security scripting.
- Blue Team utilities.

---

## Development Environment

### Python Virtual Environment

A virtual environment is used to isolate project dependencies.

Environment:

- .venv

Activation command:

source .venv/bin/activate

---

## Version Control

### Git

Git is used to manage the history and versions of the project.

Current version:

- Git 2.53.0

Main commands used:

git status
git add .
git commit
git pull
git push

---

## Repository Platform

### GitHub

GitHub is used as the central repository for the laboratory.

Main purposes:

- Code synchronization.
- Version control.
- Documentation.
- Portfolio development.
- Publication of authorized laboratory work.

Authentication method:

- SSH
- ED25519 keys

---

## Operating System

### Kali Linux

Kali Linux is the primary operating system used for cybersecurity experiments.

The environment provides access to security tools used for:

- Network analysis.
- Information gathering.
- Security testing.
- Python development.

---

## Network Analysis

### Nmap

Nmap will be used in authorized laboratory environments to:

- Identify active hosts.
- Analyze open ports.
- Identify network services.
- Support controlled security assessments.
