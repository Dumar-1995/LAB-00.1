# Laboratory Environment

## Overview

This document describes the environment used to develop the Cybersecurity Python Lab.

The laboratory was created to practice Python programming, cybersecurity concepts, automation, information gathering, network analysis, and defensive security techniques in controlled and authorized environments.

---

## Operating System

- **Distribution:** Kali Linux
- **Platform:** Linux
- **Architecture:** amd64

Kali Linux is used as the primary operating system for this laboratory because it provides a suitable environment for cybersecurity learning and security testing.

---

## Python Environment

- **Python Version:** 3.13.12
- **Environment Type:** Python Virtual Environment
- **Virtual Environment:** .venv

A Python virtual environment is used to isolate project dependencies and avoid conflicts with system packages.

---

## Version Control

- **Git Version:** 2.53.0
- **Repository:** GitHub
- **Authentication:** SSH with ED25519 keys

Git and GitHub are used to maintain version control and synchronize the laboratory between different machines.

## Security Notice

All experiments in this project must be performed exclusively in:

- Personal laboratory environments.
- Authorized systems.
- Virtual machines.
- Personal VPS infrastructure.
- Intentionally vulnerable applications.
- Controlled environments.

Unauthorized testing against third-party systems is prohibited.
